# End-to-end test: Rapid Prenatal Exome Sequencing

Test cases for the NW-GMSA IG scenario [Rapid Prenatal Exome Sequencing](https://nw-gmsa.github.io/en/ExampleScenario-RapidPrenatalExomeSequencing.html) (clinical indication R21). The fetal medicine unit at St Mary's Hospital, Manchester University NHS FT (`R0A`) orders from the North West GLH (`699X0`, iGene), the home GLH. The North West GLH does the first-line tests and sends a sub-order through GOMS to North Thames GLH, the testing GLH.

GOMS is **simulated** for now: the files under `GOMS/` are the FHIR payloads the RIE would post to, or get back from, GOMS. The plan is to connect to the GOMS Int environment later. The files under `V2/` are the NW side (MFT EPR and iGene to and from the RIE). All the fixtures are generated by `../build_glh_sub_order_scenarios.py`.

The report is sent to the central repository (NHS England Unified Genomic Record, UGR) as an `MDM^T02` with the report as a PDF. A FHIR Document may replace the PDF later.

## Running

- The v2 cases are registered in `IntegrationTest.py` as the `prenatal_exome` group: `python3 IntegrationTest.py --group prenatal_exome`.
- The `GOMS/` payloads are what a GOMS simulator should accept (PRE-03G) or return (PRE-04G, PRE-04aG, PRE-05G). They are not run by `IntegrationTest.py`.

## Known gaps

- North Thames GLH's ODS code is taken to be `69A70`, "LONDON NORTH GENOMIC LABORATORY HUB (GLH)" in the NHS ODS directory. Check it against the GOMS onboarding details; to change it, set `NORTH_THAMES_GLH_ODS` in `../build_glh_sub_order_scenarios.py` and re-run it.
- The Test Directory has no code for rapid prenatal exome sequencing in this IG's code system, so the sub-order uses `R21`.
- North Thames GLH's report number system is not confirmed either; the fixtures use the placeholder `https://fhir.example.nhs.uk/NorthThamesGLH/ReportIdentifier` (`NORTH_THAMES_REPORT_SYSTEM` in the script).
- PRE-05G fails IG validation on the North Thames report's `subject.identifier`: the IG's DiagnosticReport profile requires an NHS number there, which a fetus does not have. This is a gap in the IG profile, not in the fixture.
- The simulated GOMS base URL is `https://goms.simulated.example.nhs.uk/FHIR/R4` (`GOMS` in the script).
